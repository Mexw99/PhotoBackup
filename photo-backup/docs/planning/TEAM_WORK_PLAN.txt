======================================================================

คนที่ 1: วางระบบหลักและหน้าเริ่มต้น

----------------------------------------------------------------------
Backend

  - ตั้งค่า SQLite
  - ตั้งค่า GORM
  - สร้าง Model หลัก

      Photo
      Tag
      PhotoTag

  - สร้างฐานข้อมูลตอนเปิดโปรแกรม
  - ทำ AutoMigrate
  - เตรียม Repository เบื้องต้น
  - กำหนดรูปแบบข้อมูลที่ทุกคนต้องใช้
  - สร้าง API ตรวจสอบสถานะระบบ เช่น Database พร้อมใช้งานหรือไม่

----------------------------------------------------------------------
Frontend

  ทำหน้าเริ่มต้นของโปรแกรม:

  - ชื่อโปรแกรม PhotoBackup
  - เมนู Backup
  - เมนูจัดการ Tag
  - เมนูค้นหารูป
  - แสดงสถานะ SQLite ว่าเชื่อมต่อแล้ว
  - แสดงจำนวนรูปในระบบตอนนี้

----------------------------------------------------------------------
ผลลัพธ์ที่ต้องส่งมอบ

  เปิดโปรแกรมแล้วเห็นหน้า Dashboard และแสดงได้ว่า:

      Database: Connected
      Photos: 0
      Tags: 0
      System: Ready

----------------------------------------------------------------------
ไฟล์ที่รับผิดชอบ

  database/
  model/
  repository/
  app.go
  frontend/app/app.vue
  frontend/app/pages/index.vue
  frontend/app/components/layout/

  เมื่อเสร็จแล้วต้อง Commit และส่งให้คนที่ 2


======================================================================

คนที่ 2: ระบบ Backup รูปภาพ

เริ่มจากโค้ดของคนที่ 1

----------------------------------------------------------------------
Backend

  - เปิด Dialog ให้เลือกโฟลเดอร์ต้นทาง
  - เปิด Dialog ให้เลือกโฟลเดอร์ปลายทาง
  - อ่านไฟล์ใน Flash Drive
  - อ่านโฟลเดอร์ย่อยได้
  - เลือกเฉพาะไฟล์:

      .jpg
      .jpeg
      .png

  - คัดลอกรูปไปยังโฟลเดอร์ปลายทาง
  - ป้องกันชื่อไฟล์ซ้ำ
  - บันทึกข้อมูลรูปลง SQLite
  - นับจำนวนรูปที่สำเร็จและล้มเหลว
  - ส่งสถานะความคืบหน้าให้ Frontend

----------------------------------------------------------------------
Frontend

  สร้างหน้า Backup:

  - ปุ่มเลือกโฟลเดอร์ต้นทาง
  - ปุ่มเลือกโฟลเดอร์ปลายทาง
  - แสดง Path ที่เลือก
  - ปุ่มเริ่ม Backup
  - Progress bar
  - แสดงจำนวนรูปที่ทำไปแล้ว
  - แสดงรายการรูปที่ Backup สำเร็จ
  - แสดงข้อความ Error ถ้าคัดลอกไม่ได้

----------------------------------------------------------------------
ผลลัพธ์ที่ต้องส่งมอบ

  สามารถสาธิตได้ว่า:

      เลือกโฟลเดอร์รูป
          -> กด Backup
          -> รูปถูกคัดลอก
          -> ข้อมูลถูกบันทึกใน SQLite
          -> หน้าเว็บแสดงจำนวนรูป

----------------------------------------------------------------------
ไฟล์ที่รับผิดชอบ

  backup/
  frontend/app/pages/backup.vue
  frontend/app/components/backup/
  frontend/app/components/gallery/photo-grid.vue

  คนที่ 2 สามารถแก้ app.go เพื่อเพิ่มฟังก์ชัน Backup ได้
  แต่ต้องทำต่อจากคนที่ 1 และห้ามแก้ไฟล์ของคนที่ 1 โดยไม่จำเป็น


======================================================================

คนที่ 3: ระบบเพิ่มและจัดการ Tag

เริ่มจากระบบ Backup ของคนที่ 2

----------------------------------------------------------------------
Backend

  - เพิ่ม Tag ให้รูปภาพ
  - เพิ่ม Tag เดียวให้หลายรูป
  - ดึง Tag ของรูปภาพ
  - ลบ Tag ออกจากรูป
  - ป้องกัน Tag ชื่อซ้ำ
  - บันทึกความสัมพันธ์ในตาราง PhotoTag
  - นับจำนวนรูปของแต่ละ Tag

----------------------------------------------------------------------
Frontend

  สร้างหน้าจัดการ Tag:

  - แสดงรูปภาพที่ Backup แล้ว
  - เลือกหลายรูปพร้อมกัน
  - ช่องกรอก Tag
  - ปุ่มเพิ่ม Tag
  - แสดง Tag เป็น Badge หรือ Chip บนรูป
  - ลบ Tag ได้
  - แสดงรายการ Tag ทั้งหมด
  - แสดงจำนวนรูปของแต่ละ Tag

----------------------------------------------------------------------
ผลลัพธ์ที่ต้องส่งมอบ

  สามารถสาธิตได้ว่า:

      เลือกหลายรูป
          -> พิมพ์ Tag เช่น "ทะเล"
          -> กดเพิ่ม Tag
          -> Tag ถูกบันทึกลง SQLite
          -> ปิดเปิดโปรแกรมใหม่แล้วยังเห็น Tag

----------------------------------------------------------------------
ไฟล์ที่รับผิดชอบ

  service/
  frontend/app/pages/tags.vue
  frontend/app/components/tags/
  frontend/app/components/gallery/tag-editor.vue

  คนที่ 3 เพิ่ม API ของ Tag ใน app.go ได้
  หลังจากรับโค้ดจากคนที่ 2 แล้ว


======================================================================

คนที่ 4: ค้นหาและ Tag Cloud

เริ่มจากระบบ Tag ของคนที่ 3

----------------------------------------------------------------------
Backend

  - ค้นหารูปภาพด้วยชื่อ Tag
  - แสดงรูปหลายรูปพร้อมกัน
  - รองรับการค้นหาแบบไม่สนใจตัวพิมพ์เล็ก-ใหญ่
  - ค้นหา Tag บางส่วนได้
  - นับจำนวนรูปต่อ Tag
  - เรียง Tag จากจำนวนรูปมากไปน้อย
  - ส่งข้อมูลสำหรับสร้าง Tag Cloud

  ตัวอย่างข้อมูลที่ส่งให้ Frontend:

      [
        { "name": "ทะเล", "count": 12 },
        { "name": "ภูเขา", "count": 8 },
        { "name": "อาหาร", "count": 4 }
      ]

----------------------------------------------------------------------
Frontend

  สร้างหน้าค้นหา:

  - ช่องค้นหา Tag
  - ปุ่มค้นหา
  - แสดงผลรูปหลายรูป
  - คลิก Tag Cloud เพื่อค้นหาได้
  - ขนาดตัวอักษรของ Tag เปลี่ยนตามจำนวนรูป
  - แสดงจำนวนผลลัพธ์
  - แสดงข้อความเมื่อไม่พบรูป
  - เพิ่ม Loading และ Error State

----------------------------------------------------------------------
การทดสอบและรวมระบบ

  คนที่ 4 รับผิดชอบทดสอบ Flow ทั้งหมด:

      เลือกโฟลเดอร์
          -> Backup รูป
          -> เพิ่ม Tag
          -> ค้นหาด้วย Tag
          -> แสดงรูปหลายรูป
          -> แสดง Tag Cloud

  รวมถึงตรวจสอบว่า:

  - wails dev ทำงาน
  - wails build ทำงาน
  - ไม่มี Path ที่ใช้ได้เฉพาะ macOS
  - เตรียมทดสอบบน Windows
  - อัปเดต README สำหรับการติดตั้งและรันโปรเจกต์

----------------------------------------------------------------------
ไฟล์ที่รับผิดชอบ

  service/
  frontend/app/pages/search.vue
  frontend/app/components/search/
  frontend/app/components/tag-cloud/
  README.md
