  คนที่ 3: ระบบ Tag และ Tag Cloud                 25%
  คนที่ 4: ระบบ Search และรวมระบบ                25%

  คนที่ 1  ->  คนที่ 2  ->  คนที่ 3  ->  คนที่ 4

คนที่ 1: ระบบพื้นฐาน Database และ Dashboard

หน้าที่หลัก: วางโครงสร้างกลางที่ทุกคนใช้ต่อ และทำหน้า Dashboard

----------------------------------------------------------------------
Backend

  - ตั้งค่า SQLite และ GORM
  - กำหนดตำแหน่งเก็บไฟล์ Database ที่ใช้ได้ทั้ง macOS และ Windows
  - สร้าง Model หลัก:

      Photo
      Tag
      PhotoTag

  - กำหนด Primary Key, Unique และ Index ที่จำเป็น
  - สร้าง Database ตอนเปิดโปรแกรม
  - ทำ AutoMigrate
  - จัดการกรณีเปิด Database ไม่สำเร็จ
  - สร้าง Repository เบื้องต้นสำหรับ:

      สร้าง Photo
      ดึง Photo ทั้งหมด
      นับจำนวน Photo
      สร้าง Tag
      ดึง Tag ทั้งหมด
      นับจำนวน Tag

  - สร้าง API สำหรับ Dashboard:

      GetDatabaseStatus()
      GetPhotoCount()
      GetTagCount()
      GetRecentPhotos()

  - กำหนดรูปแบบข้อมูลและชื่อ API ให้คนที่ 2, 3 และ 4 ใช้ต่อ
  - เขียน Test สำหรับ Database และ Repository

----------------------------------------------------------------------
Frontend

  สร้างโครงหน้าและ Dashboard:

  - ทำ Layout กลางของโปรแกรม
  - ทำ Sidebar หรือเมนูหลัก
  - แสดงชื่อโปรแกรม PhotoBackup
  - แสดงสถานะ Database
  - แสดงจำนวนรูปภาพ
  - แสดงจำนวน Tag
  - แสดงรูปที่ Backup ล่าสุด ถ้ามี
  - มีเมนูไปหน้า Backup, Tags และ Search
  - ทำ Empty State กรณียังไม่มีข้อมูล

----------------------------------------------------------------------
ผลลัพธ์ที่ต้องส่งมอบ

  เมื่อเปิดโปรแกรมต้องได้ผลลัพธ์ดังนี้:

      Database: Connected
      Photos: 0
      Tags: 0
      System: Ready

  และต้องตรวจสอบได้ว่า:

      เปิดโปรแกรม
          -> สร้าง Database อัตโนมัติ
          -> สร้างตารางด้วย AutoMigrate
          -> Dashboard แสดงข้อมูลจาก Database จริง
          -> ปิดและเปิดใหม่ได้โดยข้อมูลไม่หาย

  frontend/app/components/dashboard/

คนที่ 2: ระบบ Backup รูปภาพ

หน้าที่หลัก: ทำให้ผู้ใช้เลือกโฟลเดอร์และสำรองรูปภาพได้จริง

เริ่มจาก Commit ล่าสุดของคนที่ 1

----------------------------------------------------------------------
Backend

  - เปิด Dialog ให้เลือกโฟลเดอร์ต้นทาง
  - เปิด Dialog ให้เลือกโฟลเดอร์ปลายทาง
  - อ่านไฟล์ใน Flash Drive
  - อ่านโฟลเดอร์ย่อยได้
  - รองรับเฉพาะไฟล์:

      .jpg
      .jpeg
      .png

  - ตรวจสอบว่าไฟล์ต้นทางมีอยู่จริง
  - คัดลอกรูปไปยังโฟลเดอร์ปลายทาง
  - สร้างโฟลเดอร์ปลายทางให้อัตโนมัติถ้ายังไม่มี
  - ป้องกันชื่อไฟล์ซ้ำ
  - บันทึกข้อมูลรูปลง SQLite
  - บันทึกวันที่และตำแหน่งของรูป
  - นับจำนวนรูปที่สำเร็จและล้มเหลว
  - ส่งสถานะความคืบหน้าให้ Frontend
  - จัดการกรณีไม่มีสิทธิ์อ่านหรือเขียนไฟล์
  - เขียน Test สำหรับการค้นหาไฟล์และการคัดลอก

----------------------------------------------------------------------
Frontend

  สร้างหน้า Backup:

  - ปุ่มเลือกโฟลเดอร์ต้นทาง
  - ปุ่มเลือกโฟลเดอร์ปลายทาง
  - แสดง Path ที่เลือก
  - ตรวจสอบว่าผู้ใช้เลือก Path ครบก่อนเริ่ม
  - ปุ่มเริ่ม Backup
  - ปุ่มยกเลิกหรือหยุดการทำงานถ้าทำได้ทัน
  - Progress bar
  - แสดงจำนวนรูปที่ทำไปแล้ว
  - แสดงจำนวนรูปที่สำเร็จและล้มเหลว
  - แสดงรายการรูปที่ Backup สำเร็จ
  - แสดงข้อความ Error ถ้าคัดลอกไม่ได้
  - ใช้ PhotoGrid แสดงรูปที่ Backup แล้ว

----------------------------------------------------------------------
ผลลัพธ์ที่ต้องส่งมอบ

  สามารถสาธิตได้ว่า:

      เลือกโฟลเดอร์รูป
          -> เลือกปลายทาง
          -> กด Backup
          -> รูปถูกคัดลอก
          -> ข้อมูลถูกบันทึกใน SQLite
          -> หน้าเว็บแสดง Progress และจำนวนรูป
          -> Dashboard แสดงจำนวนรูปที่เพิ่มขึ้น

----------------------------------------------------------------------
ไฟล์หลักที่รับผิดชอบ

  backup/
  frontend/app/pages/backup.vue
  frontend/app/components/backup/
  frontend/app/components/gallery/photo-grid.vue

  คนที่ 2 สามารถเพิ่มฟังก์ชัน Backup ใน app.go ได้
  แต่ต้องแก้เฉพาะส่วนของ Backup และไม่แก้โค้ดของคนที่ 1 โดยไม่จำเป็น

คนที่ 3: ระบบ Tag และ Tag Cloud

หน้าที่หลัก: ให้ผู้ใช้จัดกลุ่มรูปด้วย Tag และเตรียมข้อมูล Tag Cloud

เริ่มจาก Commit ล่าสุดของคนที่ 2

----------------------------------------------------------------------
Backend

  - เพิ่ม Tag ให้รูปภาพ
  - เพิ่ม Tag เดียวให้หลายรูป
  - ดึง Tag ของรูปภาพ
  - ลบ Tag ออกจากรูป
  - ป้องกัน Tag ชื่อซ้ำ
  - ตัดช่องว่างหน้าหลังชื่อ Tag
  - บันทึกความสัมพันธ์ในตาราง PhotoTag
  - นับจำนวนรูปของแต่ละ Tag
  - เรียง Tag จากจำนวนรูปมากไปน้อย
  - สร้างข้อมูลสำหรับ Tag Cloud เช่น ชื่อและจำนวนรูป
  - เขียน Test สำหรับการเพิ่ม ลบ และนับ Tag

----------------------------------------------------------------------
Frontend

  สร้างหน้าจัดการ Tag:

  - แสดงรูปภาพที่ Backup แล้ว
  - เลือกหลายรูปพร้อมกัน
  - ช่องกรอก Tag
  - ปุ่มเพิ่ม Tag
  - แสดง Tag เป็น Badge หรือ Chip บนรูป
  - ลบ Tag ได้
  - แสดงรายการ Tag ทั้งหมด
  - แสดงจำนวนรูปของแต่ละ Tag
  - สร้าง Component TagCloud ที่รับข้อมูลชื่อ Tag และจำนวนรูป
  - แสดง Tag ที่มีจำนวนรูปมากให้เด่นกว่า Tag อื่น

----------------------------------------------------------------------
ผลลัพธ์ที่ต้องส่งมอบ

  สามารถสาธิตได้ว่า:

      เลือกหลายรูป
          -> พิมพ์ Tag เช่น "ทะเล"
          -> กดเพิ่ม Tag
          -> Tag ถูกบันทึกลง SQLite
          -> ปิดและเปิดโปรแกรมใหม่
          -> รูปยังมี Tag เดิม
          -> Tag Cloud แสดงจำนวนรูปของแต่ละ Tag

----------------------------------------------------------------------
ไฟล์หลักที่รับผิดชอบ

  service/
  frontend/app/pages/tags.vue
  frontend/app/components/tags/
  frontend/app/components/gallery/tag-editor.vue
  frontend/app/components/tag-cloud/tag-cloud.vue

  คนที่ 3 เพิ่ม API ของ Tag ใน app.go ได้
  แต่ต้องแก้เฉพาะส่วนของ Tag และไม่แก้ Feature อื่น

คนที่ 4: ระบบค้นหา รวมระบบ และเตรียม Demo

หน้าที่หลัก: ทำให้ค้นหารูปด้วย Tag ได้ และตรวจสอบระบบตั้งแต่ต้นจนจบ

เริ่มจาก Commit ล่าสุดของคนที่ 3

----------------------------------------------------------------------
Backend

  - ค้นหารูปภาพด้วยชื่อ Tag
  - ค้นหาได้หลายรูปพร้อมกัน
  - รองรับการค้นหาแบบไม่สนใจตัวพิมพ์เล็ก-ใหญ่
  - ค้นหา Tag บางส่วนได้
  - กรองผลลัพธ์ให้ถูกต้องเมื่อรูปมีหลาย Tag
  - เรียงผลลัพธ์ตามวันที่หรือชื่อไฟล์
  - เชื่อม API Search เข้ากับข้อมูล Tag Cloud
  - จัดการกรณีค้นหาว่างหรือไม่พบรูป
  - เขียน Test สำหรับการค้นหาและผลลัพธ์หลายรูป

----------------------------------------------------------------------
Frontend

  สร้างหน้าค้นหา:

  - ช่องค้นหา Tag
  - ปุ่มค้นหา
  - ค้นหาเมื่อกดปุ่มหรือกด Enter
  - แสดงผลรูปหลายรูปพร้อมกัน
  - คลิก Tag Cloud เพื่อค้นหาได้
  - แสดงจำนวนผลลัพธ์
  - แสดงข้อความเมื่อไม่พบรูป
  - เพิ่ม Loading State
  - เพิ่ม Error State
  - ใช้ PhotoGrid และ TagCloud ที่คนก่อนหน้าสร้างไว้

----------------------------------------------------------------------
การรวมระบบและการทดสอบ

  ทดสอบ Flow ทั้งหมด:

      เปิดโปรแกรม
          -> ตรวจสอบ Database
          -> เลือกโฟลเดอร์รูป
          -> Backup รูป
          -> เพิ่ม Tag
          -> ปิดและเปิดโปรแกรมใหม่
          -> ค้นหาด้วย Tag
          -> แสดงรูปหลายรูป
          -> แสดง Tag Cloud

  ตรวจสอบเพิ่มเติม:

  - wails dev ทำงาน
  - wails build ทำงาน
  - ไม่มี Path ที่ใช้ได้เฉพาะ macOS
  - ใช้งาน Path บน Windows ได้
  - ไม่มี Error จากการปิดโปรแกรมแล้วเปิดใหม่
  - ตรวจสอบการแสดงผลกรณีไม่มีรูป
  - อัปเดต README สำหรับการติดตั้งและรันโปรเจกต์
  - เตรียมลำดับการพูดและการสาธิต Final
